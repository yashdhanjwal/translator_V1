# 🚀 Hostingial Deployment Guide (Fixed)

This guide addresses the **"Unable to fork / Resource Limit"** error you encountered in cPanel. This error happens because shared hosting servers often don't have enough RAM to run the `npm install` or `next build` commands.

To fix this, we will **build the website on your computer** and only upload the final production files to Hostingial.

---

## 🛠️ Method 1: Static Export (Recommended)

This is the most reliable way for Hostingial. It makes your site fast and avoids all "Unable to fork" errors.

### 1. Update Configuration
In your `next.config.ts`, update it to:
```typescript
import type { NextConfig } from "next";
const nextConfig: NextConfig = {
  output: 'export',
  images: { unoptimized: true },
};
export default nextConfig;
```

### 2. Build Locally
On your computer terminal, run:
```bash
npm run build
```
This will create a folder named **`out`**.

### 3. Upload to cPanel
1. Open **cPanel File Manager**.
2. Go to your subdomain folder (e.g., `ft1.yashdhanjwal.com/public_html`).
3. **Delete everything** inside it.
4. Zip the **contents** of your local `out` folder.
5. Upload the zip to cPanel and **Extract** it.
6. Your site is now live at `ft1.yashdhanjwal.com`.

---

## 🖥️ Method 2: Node.js Selector (To fix your current error)

If you must use the cPanel Node.js Selector, follow these steps to bypass the memory limits.

### 1. Build Standalone Locally
Ensure `output: 'standalone'` is in your `next.config.ts`.
On your computer, run:
```bash
npm run build
```
Next.js will create a folder at **`.next/standalone`**.

### 2. Prepare for Upload
1. Go into the `.next/standalone` folder on your computer.
2. Copy your local `public` folder into `.next/standalone/public`.
3. Copy your local `.next/static` folder into `.next/standalone/.next/static`.
4. Zip **everything inside** the `.next/standalone` folder (including the `server.js` that Next.js generated).

### 3. Upload to Hostingial
1. In cPanel File Manager, go to your **Application Root**: `ft1.yashdhanjwal.com/public_html`.
2. Upload the zip file and **Extract** it.

### 4. Configure Node.js Selector
Go back to the **cPanel Node.js Selector** and use these settings:
- **Node.js Version**: Select **20.x** or **22.x**.
- **Application mode**: Production
- **Application root**: `ft1.yashdhanjwal.com/public_html`
- **Application URL**: `ft1.yashdhanjwal.com`
- **Application startup file**: `server.js` (This refers to the file generated by Next.js in the standalone folder).

**CRITICAL**: Do **NOT** click "Run JS Script" or "npm install" in cPanel. Just click **RESTART** or **START**.

---

## ✅ Why this works
The "Unable to fork" error is caused by the server running out of memory while trying to compile your code. By building it on your computer and uploading the "standalone" version, the server only has to *run* the code, which uses very little memory.
